# MS-Image 英文术语中英对照

本文是 `ms-image` 全部设计、工程证据和历史文档共用的英文术语表。英文标识符必须保持原样，中文用于理解含义；例如 `task_record` 仍然是数据库表名，但含义是“任务记录表”。

## 阅读规则

| 英文形式 | 中文说明 |
|---|---|
| `code`、`table_name`、`field_name`、`API path`、文件路径 | 技术标识符，必须保持英文原样；中文只解释含义 |
| `status`、`type`、`role`、`scope` 等字段值 | 状态、类型、角色、作用域，表格中会同时给出中文含义 |
| `CURRENT`、`PROPOSED`、`UNKNOWN` 等大写词 | 文档事实等级或发布状态，不能按普通英文句子理解 |
| `v1`、`v2`、`SHA256`、`ID`、`UTC` | 版本、摘要算法、标识符、时间标准，保留缩写 |

### 阶段服务用途

目标代码只注册下列 5 个 Stage Service（阶段服务）；默认 `xray_primary_v1` 只执行第 1、2、5 个。当前仓库尚未实现这些目标 Stage，以下名称是开发合同，不是运行事实：

| English Stage Service | 中文用途 |
|---|---|
| `StudyPreparationStageService` | 加载冻结 Study revision/原图，校验完整性、投照覆盖、Provider capability、预算和泄漏 |
| `XRayJointPrimaryReaderStageService` | 使用完整原图生成 X 光主读候选结果 |
| `XRayFamilyRoutingStageService` | 仅在 targeted Profile 中按冻结规则选择 Primary 直接定稿或最多一次专项复核；不调用模型、不改医学结论 |
| `XRayTargetedReviewStageService` | 仅在 Router 触发时对一个临床专项家族执行一次补充读片，并输出完整病例结果 |
| `DecisionFinalizationStageService` | 选择并校验唯一 Primary/Targeted owner，返回定稿选择；由 ImagingExecutionService + ReportService 原子保存 Report/Task 终态；本 Stage 不调用模型、不改判、不自行 commit |

CT/MRI/视频/WSI 的 `ShardFanOutStageService`（分片扇出阶段服务）和
`DeterministicFanInStageService`（确定性汇合阶段服务）属于条件扩展，未完成对应模态资格验证前不注册到生产 Profile。

## 跨会话交接

| English | 中文 |
|---|---|
| Agent Handoff | 代理交接；用于下一会话恢复当前目标、状态和风险 |

| Recovery Reading Order | 恢复阅读顺序；新会话按最小必要文件恢复上下文 |
| Workspace Map | 工作区地图；保存仓库结构、入口和长期规则 |
| Decision Log | 决策日志；保存跨会话有效的取舍、理由和证据 |
| Work Log | 工作日志；保存近期实际修改及结果 |
| Validation History | 验证历史；保存已运行、失败和未运行的检查 |
