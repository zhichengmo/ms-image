## 2026-08-27 — 第三个逐接口切片：新增 `GET /images/page`

- 新增 `ImagePageQuery`、`ImagePageItemResponse` 和内部 `ImagePageResult`；查询必传 `series_id`，支持 status、image_role、current/history、page/page_size，最大页长 100。
- 新增 `ImageDal.page_for_series()`：复用 `DalBase.get_datas()`，以相关 `NOT EXISTS` 选择每个 logical key 的绝对最新版本，默认排除 superseded/deleted，并按 sequence/logical/version/id 稳定排序。
- DAL 使用 `load_only` 精确加载分页 DTO 列；对象存储、KMS、validation lease、source manifest 和 technical metadata JSON 不进入分页读取。
- 新增 `ImageService.page_images()`：先沿 Series -> Study -> Session 做一次 requester ownership 校验，再执行分页，不逐 Image 查询。
- Runtime 新增 `GET /api/v1/images/page`，返回统一 `PagedResponse[ImagePageItemResponse]`；ID 仍使用 query 参数，没有 `/{id}`。
- 更新 30 号接口审计清单 §6.11、近期接口顺序和 Slice 3，写明 include_versions 优先级、最新工作流版本/最新 ready 版本差异、验证结果和大 Series 性能边界。
- 未修改数据库表、Model、迁移或测试文件；没有写入或保留验证数据。
