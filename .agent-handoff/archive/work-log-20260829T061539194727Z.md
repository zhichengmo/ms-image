## 2026-08-28 — 第四个逐接口切片：新增 `GET /tasks/page`

- 新增 `TaskPageQuery`、精简 `TaskStatusResponse` 和内部 `TaskPageResult`；至少提供 `session_id` 或 `study_id`，支持 execution status、task type、带时区的创建时间闭区间及 1..100 分页。
- 新增 `TaskDal.page_for_owner()`：继续复用 `DalBase.get_datas()`；Session scope 仅在 DAL 内关联 Study，查询始终强制 `Task.requester_id`，并按 `created_at DESC, id DESC` 稳定排序。
- DAL 使用 `load_only` 只读取分页 DTO 字段；不读取或返回 request snapshot、预算、Pipeline/assignment hash、错误消息和取消原因。
- 新增 `TaskService.page_tasks()`：先校验指定 Study/Session 的父 Session owner；两个 scope 同时提供但不匹配时 fail-closed，随后由 DAL 再执行 Task requester 隔离。
- Runtime 新增 `GET /api/v1/tasks/page`，返回统一 `PagedResponse[TaskStatusResponse]`；资源 ID 仍使用 query 参数，没有 `/{id}`。
- 更新 30 号接口清单 §7.4、L1 判定、近期顺序和 Slice 7；下一接口收敛为 owner-safe 的 `GET /reports/current?task_id=`。
- 本轮未修改数据库表、Model、迁移或测试文件；真实数据库验证为只读，没有写入或清理业务数据。
