## 2026-08-28 — 第六个逐接口切片：Session complete/cancel 联动 Task

- `SessionDal` 新增 Session 行锁读取；`TaskDal` 新增统一 Task 终态集合和按 Session 查询/稳定顺序锁定非终态 Task 的方法，关联关系保持 `Task -> Study -> session_id`。
- `SessionService.complete_session()` 在 completed 幂等重放和首次状态推进前都扫描非终态 Task；存在 queued/running/retry_wait/pending Task 时返回 `session_tasks_active`。
- `SessionService.cancel_session()` 在同一请求事务中锁 Session 和全部非终态 Task，只为尚未收到请求的 Task 写取消 actor/reason/time，再 CAS Session 为 cancelled；terminal Task 保持不变，同 reason 重放可修复历史不一致。
- `TaskService.create_task()` 改为锁定父 Session，只有 open/processing 可创建全新 Task；终态 Session 下已有 business key 仍继续原有 Study/Config/Snapshot/hash 幂等校验。
- 复核 Worker、AI request 与 Report finalization 的取消门禁，确认 cancel 响应不伪造 Task 终态，调用方仍需轮询 Task 收敛。
- 更新 30 号接口清单和 durable handoff；未改 API、Model、Schema、数据库表/字段、迁移或测试文件。
