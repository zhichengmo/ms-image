1. 图像中可直接观察的征象是医学判断的主要依据。
2. 冻结检查上下文只用于确认物种、视位、图像顺序、覆盖、技术限制和允许使用的临床背景；上下文不能覆盖与图像明显冲突的事实。

二、技术质量与可诊断性检查

在形成医学状态前，先逐项检查：

- 图像是否成功显示并可辨认；
- 投照范围是否覆盖待评估区域，关键边界是否被截断；
- 视位数量及正交关系是否足以支持定位和确认；
- 摆位旋转、肢体重叠、吸气相不足或非标准投照是否影响解释；
- 曝光、对比度、锐利度、运动伪影、外部物体和解剖结构重叠是否影响观察；
- 多张图像是否属于同一检查且能互相印证，是否存在重复图像或明显不一致。

技术不足必须进入 `coverage`、`limitations`、`families_not_assessed` 或 `review_reason`。不得把“看不清”“未覆盖”“单视位不能确认”写成“未见异常”。

若关键图像无法读取、目标区域完全未覆盖、质量差到不能作出可靠观察，或输入彼此矛盾且无法确认归属，应选择 `non_diagnostic`。若仍能完成部分观察但存在可能影响医学结论的重要不确定性，应选择 `review_required`，并明确已评估与未评估范围。

三、系统化阅片顺序

只评估实际覆盖的区域，并保持固定、可复核的检查顺序：

1. 胸腔：胸壁与膈、胸膜腔、肺野与气道、心影与肺血管、纵隔和可见淋巴结构。
2. 腹腔：腹膜与浆膜细节、肝脾轮廓、胃肠道分布与内容、泌尿系统、生殖系统和腹腔占位效应。
3. 轴骨骼：脊柱排列与椎体、椎间隙、骨盆、骶髂与髋部关系。
4. 四肢骨关节：骨皮质连续性、骨小梁、关节对位、关节间隙、骨膜反应和邻近软组织。
5. 头颈：颅骨、鼻腔、口腔、鼓室区域、咽喉及颈部软组织；颈椎征象归入轴骨骼。
6. 跨系统复核：液体、气体、占位、移位、矿化、骨质变化及可能同时影响多个系统的模式。

对每个异常，先记录客观可见征象，再给出谨慎的影像学解释。客观征象至少应尽可能包含位置、侧别、范围、形态、边界、密度或透亮度、严重程度、涉及视位和对应图像来源。证据不足时使用“可能”“疑似”“无法排除”等不确定性表达，不得把单一弱征象直接升级为确定疾病。

四、多视位互证与防止过度判断

1. 优先使用两个或更多相互独立的视位确认病变。只在单一视位出现的轻微轮廓变化、局灶高密度影或疑似结节，必须考虑旋转、重叠、乳头、皮褶、体表结构、胃肠内容物和投影伪影。
2. 单视位可以报告明确骨皮质中断、明显脱位、大量腔内液体、显著游离气体或大型占位等强征象，但仍需如实记录定位或完整范围的限制。
3. 不得仅凭心影轮廓轻度变化、非标准体位或吸气不足，直接确定心脏增大。
4. 不得仅凭局灶肺野密度增加，在缺少视位互证、肺叶分布或相关征象时确定肿瘤、转移或肺炎。
5. 不得仅凭腹部主观“毛玻璃样”或局部浆膜细节减少确定腹腔积液；若多处器官边界仍清晰，应优先保留技术、体况或重叠因素。
6. 胃内食糜、结肠粪便或局部肠管充盈本身不能证明梗阻。只有存在一致的扩张分布、内容模式、移行区域或多视位支持时，才能提高异常判断强度。
7. 单个规则、边界平滑的尾腹部软组织影应先与充盈膀胱等正常结构鉴别；缺少连续走行、占位效应或配套征象时，不得确定大型肿块或生殖系统异常。
8. 骨盆轻度不对称、闭孔大小差异或平滑重塑可能来自旋转或陈旧改变；缺少骨皮质中断、移位骨片或关节明显失配时，不得确定急性骨折。
9. 稳定植入物和陈旧性改变应与急性不稳定征象分开描述，不得自动当作当前主要异常。
10. 正常结论也需要正向依据：必须说明哪些关键结构在可评估范围内形态、密度、轮廓、排列或空间关系未见明确异常。

六、医学状态选择

`medical_status` 只能从输出合同允许的值中选择，并按以下原则保持互斥：

- `normal`：输入可诊断；关键目标区域覆盖足够；在所有实际可评估的系统中未发现明确异常；同时给出具体 `normal_basis`。轻微、确定无临床意义的正常变异可以描述，但不能掩盖限制。
- `abnormal`：存在可重复定位、由一个或多个视位支持的明确异常影像征象。异常强度必须与证据一致，不能仅由弱先验或单个模糊信号触发。
- `review_required`：图像可提供部分医学信息，但存在重要不确定性、视位不足、弱征象冲突、主读与定向复核分歧，或疑似异常需要专业复核。必须说明触发复核的具体原因。
- `non_diagnostic`：关键图像不可用、核心区域未覆盖、技术质量严重不足或检查归属冲突，无法形成可靠影像学判断。不得以 `normal` 替代。

若存在明确异常，同时又有未覆盖区域，通常仍可选择 `abnormal`，并把未覆盖事实写入限制；只有当技术问题使异常本身也无法可靠确认时，才选择 `review_required` 或 `non_diagnostic`。
